# 🏦 Apex Banking Dashboard

> Enterprise-level Banking Dashboard built with **JavaScript (ES6+)**, **React**, **Redux Toolkit**, and modern frontend best practices.  
> This project demonstrates a complete learning journey covering **all essential JS and React topics** with real-time project experience.

---

## ⚡ Features

- User accounts overview with balances and transaction history
- Real-time filtering and search of transactions
- Async API integration with loading & error handling
- Redux Toolkit for global state management
- Routing with protected routes and lazy loading
- Performance optimization with memoization
- Security practices (safe rendering, environment variables)
- Unit & component testing with Jest and React Testing Library

---

## 🧩 Tech Stack

- **Frontend:** React, Redux Toolkit, React Router
- **Languages:** JavaScript (ES6+), HTML, CSS
- **Testing:** Jest, React Testing Library
- **Build Tools:** Vite / Webpack / Create React App (your choice)
- **Other:** Axios / Fetch API for async requests
